# แผนใบลดหนี้ (แอปขาย) — ร่างให้ผู้ใช้ตัดสินก่อนลงมือ (2026-11-05)

> สถานะ: **เฟส 1 เสร็จ (D159 · 0106 · 2026-11-05)** — ผู้ใช้ตัดสิน: ใบลดหนี้ยกเว้นเดือนเดียวกัน · ลดทั้งออเดอร์ตอนยกเลิก · ฝั่งซื้อไว้ทีหลัง · ⏳ เฟส 2 ลดบางส่วน · ⏳ ผู้สอบบัญชียืนยันการกรอก ภพ.30

## 1. ปัญหาที่แก้

ยกเลิกออเดอร์ตอนนี้ (`fn_cancel_order`) = เปลี่ยนบิลรายรับเดิมเป็น `ยกเลิก`
⇒ ภาษีขายหายจาก **เดือนที่ออกใบกำกับ** ย้อนหลัง ทั้งที่เดือนนั้นอาจยื่น ภพ.30 ไปแล้ว
ตามกฎหมาย ภาษีขายที่ลดลงต้องไปหักใน **เดือนที่ออกใบลดหนี้** (ม.82/10 · ป.80/2542 ข้อ 5) และงวดเดิมไม่ขยับ

## 2. กฎหมายที่ต้องตาม (สรุปจากแหล่งในหัวข้อ 8)

**ออกได้เมื่อไร (ม.82/10 + ประกาศอธิบดีฉบับที่ 82)** — ต้องเข้าเหตุใดเหตุหนึ่ง:
- ลดราคาเพราะสินค้าผิดข้อกำหนด/ชำรุด/ขาดจำนวน/คำนวณราคาผิดสูงกว่าจริง — 82/10(1)
- รับสินค้าคืนเพราะชำรุด/ไม่ตรงตัวอย่าง/ไม่ตรงคำพรรณนา — 82/10(3)
- คืนเงินจ่ายล่วงหน้า/เงินมัดจำ/เงินจองตามข้อตกลงทางการค้า — ประกาศ 82 ข้อ 2(2)
- คืนหรือแลกเปลี่ยนสินค้าตามข้อตกลงทางการค้า (ภายในเวลาอันสมควร) — ประกาศ 82 ข้อ 2(3)(4)
- จ่ายเงินชดเชยตามข้อผูกพันในกฎหมาย — ประกาศ 82 ข้อ 2(1)
- ⚠️ "ลูกค้าเปลี่ยนใจยกเลิกเฉย ๆ" ไม่มีเหตุตรงตัว — ต้องเข้าข้อตกลงคืนสินค้า/คืนมัดจำ ไม่งั้นสรรพากรอาจไม่รับใบลดหนี้ (มีข้อหารือที่วินิจฉัยว่าไม่เข้าเหตุ) → หน้าจอบังคับเลือกเหตุ

**ต้องออกเดือนไหน (ม.86/10)** — เดือนภาษีที่เหตุเกิด (มีเหตุจำเป็นออกเดือนถัดไปได้)

**รายการที่ต้องมีบนใบ (ม.86/10 (1)-(7))**
1. คำว่า **"ใบลดหนี้"** เห็นเด่นชัด (ข้อหารือ 0811/พ.10090: พิมพ์ว่า "ใบหักหนี้" = ผิดสาระสำคัญ ม.90(12))
2. ชื่อ ที่อยู่ เลขประจำตัวผู้เสียภาษีของผู้ออก
3. ชื่อ ที่อยู่ผู้ซื้อ (เราใส่เลขภาษี+สาขาผู้ซื้อด้วยเหมือนใบกำกับ)
4. วันเดือนปีที่ออกใบลดหนี้
5. **เลขที่ใบกำกับภาษีเดิม · มูลค่าเดิม · มูลค่าที่ถูกต้อง · ผลต่าง · ภาษีของผลต่าง**
6. คำอธิบายสั้น ๆ ถึงสาเหตุ
7. ข้อความอื่นที่อธิบดีกำหนด (ประกาศฉบับที่ 249 — ยังไม่ได้อ่านตัวประกาศ ⏳)
- ถือเป็นใบกำกับภาษี ⇒ เลขที่ต้องเรียงต่อเนื่อง · ต้นฉบับให้ลูกค้า สำเนาเก็บ
- **ใบลดหนี้ 1 ใบอ้างใบกำกับเดิมได้หลายใบ** (ป.80/2542 ข้อ 4) → ออเดอร์มัดจำ+ยอดค้าง ออกใบเดียวได้

**ผู้ไม่จด VAT** ออกใบลดหนี้ไม่ได้ (เป็นใบกำกับภาษี) → คงการยกเลิกแบบเดิม

## 3. การยื่น ภพ.30

- ใบลดหนี้ลง **รายงานภาษีขายของเดือนที่ออกใบลดหนี้** เป็นแถวติดลบ (อ้างเลขใบกำกับเดิม) → ยอดขาย/ภาษีขายของเดือนนั้นเป็นยอดสุทธิ
- งวดเดิมไม่แก้ ไม่ต้องยื่นเพิ่มเติม
- ถ้าภาษีขายสุทธิของเดือนติดลบ → ภาษีซื้อยกไปเดือนหน้า (สูตรเดิมรองรับอยู่แล้ว `forwardedVatOut`)
- ⚠️ **ยังหาคำแนะนำการกรอกแบบ ภพ.30 ทางการไม่เจอ** ว่าช่อง "ยอดขายในเดือนนี้" ให้กรอกยอดสุทธิหลังหักใบลดหนี้ — แนวปฏิบัติทั่วไปคือยอดสุทธิ · ⏳ ให้ผู้สอบบัญชียืนยัน

## 4. ออกแบบที่เสนอ

**4.1 เมื่อไรใช้ใบลดหนี้ เมื่อไรยกเลิกแบบเดิม** ← ผู้ใช้ตัดสิน (คำถาม 1)
- ออเดอร์ที่ **ยังไม่มีใบกำกับภาษี** (มีแค่ใบเสนอราคา/ใบแจ้งหนี้) · กิจการไม่จด VAT → ยกเลิกแบบเดิม
- ออเดอร์ที่ **ออกใบกำกับแล้ว** → ใบลดหนี้ (เสนอ) · ยกเว้นทางเลือก: เดือนเดียวกัน + ยังไม่ติ๊กยื่น ภพ.30 (D95) + เรียกใบเดิมคืนได้ → ยกเลิกแบบเดิมตาม ป.86/2542 ข้อ 25

**4.2 หน้าจอ** — ปุ่ม "ยกเลิก" ของออเดอร์ที่มีใบกำกับเปลี่ยนเป็นกล่อง *ยกเลิก + ออกใบลดหนี้*:
- เหตุ (ดร็อปดาวน์ตามข้อ 2 + ช่องอธิบาย) · วันที่ใบลดหนี้ (ปริยายวันนี้ · ห้ามก่อนวันใบกำกับเดิม)
- ยอดที่ลด = ทั้งออเดอร์ (เฟสแรก) · คืนเงินจากบัญชีไหน หรือ *ยังไม่คืน (ตั้งค้างจ่าย)* → คืนทีหลังด้วยปุ่มชำระเดิม (D123)
- สต็อก/ฟอร์ม ภส. → ใช้ตรรกะยกเลิกเดิมทั้งหมด (คืนสต็อก · D90/D91)

**4.3 เอกสาร** — หน้าตาเดียวกับใบกำกับในแอปขาย (หัวกระดาษ · กล่องลูกค้า · ตารางรายการ · ต้นฉบับ/สำเนา · คัดลอกเป็นภาพ/แชร์)
- หัว **ใบลดหนี้ / Credit Note** · เลขชุดใหม่ `CN` (ตั้งรูปแบบได้ที่ ตั้งค่า → เลขเอกสาร · D100)
- กล่องอ้างอิง: เลขใบกำกับเดิมทุกใบ + วันที่
- สรุปท้าย: มูลค่าเดิม · มูลค่าที่ถูกต้อง · ผลต่าง (ก่อน VAT) · VAT ของผลต่าง · รวมคืน
- บรรทัดเหตุผล + ลายเซ็นผู้รับ/ผู้มีอำนาจ · ปุ่มพิมพ์ซ้ำในแท็บ ปิด / ยกเลิก

**4.4 บัญชี/ภาษี**
- บิลรายรับเดิม **คงสถานะปกติ** (งวดเดิมไม่ขยับ)
- บิลใหม่ type ใหม่ **`ลดหนี้ขาย`** ลงวันที่ใบลดหนี้: มูลค่า/VAT ของผลต่าง · เงินออกจากบัญชีที่คืน (หรือค้างจ่าย)
- `taxReport` (ภพ.30): นับ `ลดหนี้ขาย` เป็นแถวติดลบในภาษีขาย ← **แก้สูตร** · golden เดิมต้องผ่านโดยไม่แก้ไฟล์เทส + golden ใหม่
- แดชบอร์ด: หักรายได้เดือนนั้น · statement: เงินออก · ภงด.3/53 ไม่เกี่ยว
- ⚠️ ลูกค้าหัก ณ ที่จ่ายไว้ตอนจ่าย → คืนเงินสุทธิ · ใบ 50ทวิ ที่ลูกค้าออกให้เราไม่ถูกแตะ (แจ้งเตือนบนจอ)

## 5. ขอบเขต ← ผู้ใช้ตัดสิน (คำถาม 2-3)
- เฟส 1 (เสนอ): ลดหนี้ทั้งออเดอร์ ตอนยกเลิก · ฝั่งขายเท่านั้น
- เฟส 2: ลดบางส่วน (คืนบางรายการ/ลดราคา) โดยไม่ยกเลิกออเดอร์
- เฟส 3: ใบลดหนี้ที่**ได้รับ**จากผู้ขาย (ลดภาษีซื้อเดือนที่ได้รับ) ฝั่งบัญชี
