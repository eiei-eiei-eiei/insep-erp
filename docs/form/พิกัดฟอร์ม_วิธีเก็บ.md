# วิธีเก็บพิกัดฟอร์ม สรรพสามิต (ให้ AI กรอกตัวเลข PDF)

เป้าหมาย: คุณหาพิกัดเอง (หรือร่วมกับ AI อื่น) แล้วส่งตัวเลขกลับมา ผมแปลงเป็นโค้ดให้ — ไม่ต้องให้ผมอ่านรูป (ประหยัด token มาก)

---

## เครื่องมือ: `pdf_coord_picker.html`

1. ดับเบิลคลิกเปิดไฟล์ในเบราว์เซอร์ (Chrome/Edge) — ต้องต่อเน็ต (โหลด pdf.js)
2. กดเลือกไฟล์ PDF ฟอร์ม
3. **เลื่อนเมาส์** = เห็นพิกัดสด (มุมขวาบน) · **คลิก** = บันทึกจุด
4. ก่อนคลิกแต่ละจุด ตั้ง 3 อย่าง:
   - **ป้ายชื่อ** = ชื่อช่อง (พิมพ์ไทยได้ เช่น `header_ชื่อโรงงาน`, `col_จำนวนรับ`)
   - **ชนิด** = point / col / rowTop / rowBottom (อธิบายด้านล่าง)
   - **จัดชิด** = ซ้าย(ข้อความ) / ขวา(ตัวเลข) / กลาง(เลขลำดับ)
5. คลิกครบแล้วกด **คัดลอกทั้งหมด** → ส่งข้อความกลับมาให้ผม

> พิกัดที่ได้อยู่ในระบบเดียวกับ pdf-lib แล้ว (หน่วยจุด, origin มุมล่างซ้าย) — ส่งมาดิบๆ ได้เลย ไม่ต้องแปลง

---

## หลักการคลิก (สำคัญ — ผิดตรงนี้ตัวอักษรจะเยื้อง)

| สิ่งที่กรอก | จัดชิด | คลิกตรงไหน |
|---|---|---|
| ตัวเลข (รับ/จ่าย/คงเหลือ/ปริมาณ/ดีกรี) | **ขวา (R)** | **ขอบขวา**ของช่อง (เลขจะชิดขวาเหมือนฟอร์มบัญชี) |
| ข้อความ (ชื่อโรงงาน, รายการ, batch) | **ซ้าย (L)** | **จุดเริ่ม**ด้านซ้ายของช่อง |
| เลขลำดับ/วันที่ (๑–๓๑) | **กลาง (C)** | **กึ่งกลาง**ช่อง |
| ตำแหน่งแนวตั้ง (y ของบรรทัด) | — | คลิกตรงระดับที่อยากให้ **ฐานตัวอักษร (baseline)** วาง — กะระยะชิดเส้นล่างเองได้เลย ผมใช้ค่า y ที่คุณคลิกตรงๆ |

---

## 4 ชนิดของจุด

- **point** — จุดเดี่ยว เก็บทั้ง x,y (ใช้กับ header / แถวรวม / กล่องเลขทะเบียน) → คลิก 1 ครั้งต่อช่อง
- **col** — คอลัมน์ในตาราง เก็บแค่ **x** (ตำแหน่งแนวนอน) → คลิกที่คอลัมน์นั้น **ที่แถวแรกที่ต้องกรอก** ตรงขอบซ้าย/ขวาตามการจัดชิดของข้อมูล (ค่า y ไม่ใช้ — มาจาก rowFirst/rowLast)
- **rowFirst** — **baseline ของแถวข้อมูลแรก** (คลิกตรงระดับที่อยากให้ตัวอักษรแถวแรกวาง)
- **rowLast** — **baseline ของแถวข้อมูลสุดท้าย** (คลิกตรงระดับที่อยากให้ตัวอักษรแถวสุดท้ายวาง)

> ทำไมใช้ rowFirst/rowLast (baseline) แทนเส้นตาราง? ผมคำนวณ baseline ของทุกแถวจาก 2 จุดนี้แบบเชิงเส้น:
> `baseline[k] = rowFirst.y + (rowLast.y − rowFirst.y) × (k−1)/(N−1)`
> ได้ระยะเท่ากันเป๊ะทุกแถว **และคุณคุมระยะชิดเส้นเองตั้งแต่ตอนคลิก** ผมไม่ต้องเดา +3 จุดอีก
>
> เคล็ดลับ: คลิก rowFirst/rowLast ให้ baseline อยู่สูงจากเส้นล่างของช่องสัก 2–3 จุด (ตัวอักษรจะลอยพ้นเส้น ไม่ทับ)

## สิ่งที่ต้องเก็บต่อ 1 ฟอร์ม (checklist)

**A. Header** — ทุกช่องว่างหัวกระดาษที่ต้องกรอก: ใช้ชนิด `point` ตั้งป้าย `header_xxx`
   - checkbox (โรงเล็ก/กลาง): `point` ป้าย `chk_โรงเล็ก` คลิกกลางช่อง ✓

**A.1 ช่องกล่องเลขทะเบียนสรรพสามิต (แบบ 13 - 1 - 3 ช่อง)** ⚠️
   กระจายจากกล่องแรกถึงสุดท้ายรวดเดียว**ไม่ได้** เพราะมีขีดคั่นเป็นช่องว่างระหว่างกลุ่ม → เก็บ **ทีละกลุ่ม**
   แต่ละกลุ่มกล่องด้านในเรียงเท่ากัน คลิกแค่กล่องแรก+สุดท้ายของกลุ่มนั้น แล้วบอกจำนวนกล่อง:

   | คลิก | ชนิด | ป้าย | หมายเหตุ |
   |---|---|---|---|
   | กึ่งกลางกล่อง 1 ของกลุ่มแรก | point (align C) | `reg_g1_first` | กลุ่มนี้มี 13 กล่อง |
   | กึ่งกลางกล่อง 13 ของกลุ่มแรก | point (align C) | `reg_g1_last` | |
   | กึ่งกลางกล่องเดี่ยว | point (align C) | `reg_g2` | กลุ่มนี้มี 1 กล่อง |
   | กึ่งกลางกล่อง 1 ของกลุ่มสาม | point (align C) | `reg_g3_first` | กลุ่มนี้มี 3 กล่อง |
   | กึ่งกลางกล่อง 3 ของกลุ่มสาม | point (align C) | `reg_g3_last` | |

   แล้วบอกผม: `กลุ่ม = 13 - 1 - 3`
   ผมจะกระจาย x ภายในแต่ละกลุ่มแบบเท่ากัน (กลุ่ม 1 = 13 จุดระหว่าง g1_first…g1_last, กลุ่ม 3 = 3 จุด) ใช้ y ร่วมกัน
   *(ทุกกล่องอยู่บรรทัดเดียวกัน y เท่ากันหมด — คลิก y ไหนก็ได้ในแถวนั้น)*

**B. ตาราง** —
   - `rowFirst` 1 จุด (baseline แถวข้อมูลแรก), `rowLast` 1 จุด (baseline แถวข้อมูลสุดท้าย)
   - บอก **จำนวนแถวข้อมูล** (เช่น 31)
   - ถ้ามีแถว "ยอดยกมา" แยกเหนือแถวข้อมูล: `point` ป้าย `ยอดยกมา` (คลิกที่ช่องคงเหลือ — เก็บ x,y)
   - **ทุกคอลัมน์ที่ต้องกรอก**: ชนิด `col` คลิกที่คอลัมน์นั้น**ที่แถวแรก** ตรงขอบซ้าย/ขวาตามการจัดชิด ตั้งป้ายตามหัวคอลัมน์จริง (เช่น `col_จำนวนรับ` align R)

**C. แถวรวม** (รวมเดือนนี้ / รวมแต่ต้นปี / รวมทั้งสิ้น ฯลฯ) —
   - ชนิด `point` ป้าย `รวมเดือนนี้_รับ` ฯลฯ (คลิกตรงช่องที่จะลงเลข ใช้ x ของคอลัมน์นั้น)
   - หรือถ้าใช้ x เดียวกับคอลัมน์ตาราง: เก็บแค่ y ก็พอ บอกผมว่า "ใช้ x เดียวกับ col_xxx"

**D. หน้าหลายหน้า** — ฟอร์ม landscape มี 3 หน้า ถ้าตารางต่อเนื่องข้ามหน้า เก็บ rowFirst/rowLast ของ**ทุกหน้า**ที่มีข้อมูล (เครื่องมือใส่ `[หน้า2]` ให้อัตโนมัติ)

## 4 ฟอร์มที่ต้องทำ + ข้อมูลที่ระบบมีให้กรอก

> คุณแค่ตั้งป้ายคอลัมน์ตามหัวจริงในฟอร์ม แล้วบอกผมว่า "คอลัมน์นี้ = ข้อมูลตัวไหน" ผมจับคู่กับฟังก์ชัน backend ให้

### 1. ภส.๐๗-๐๑/๑ — บัญชีวัตถุดิบ ✅ (ทำเสร็จแล้ว ใช้เป็นตัวอย่าง)
ข้อมูลที่ระบบมี: วันที่, รายการ(ชื่อวัตถุดิบ+batch), หลักฐานเลขที่, จำนวนรับ, จำนวนจ่าย, คงเหลือ, ยอดยกมา, รวมเดือน(รับ/จ่าย), รวมปี(รับ/จ่าย)
→ ใบนี้เก็บพิกัดครบแล้ว ไม่ต้องทำซ้ำ (เก็บไว้เทียบรูปแบบ)

### 2. ภส.๐๗-๐๒/๑(๑) — บัญชีผลิตสุรา (landscape, 3 หน้า)
ข้อมูลที่ระบบ**น่าจะมี**ให้กรอก (ยืนยันกับผมตอนส่งพิกัด): วันที่ผลิต, ชนิดสุรา, batch, ปริมาณน้ำสุราที่ได้(ลิตร), ดีกรี, ปริมาณคิดเป็นลิตรแอลกอฮอล์บริสุทธิ์(LPA), คงเหลือ, รวม
→ เก็บ: header, rowTop/rowBottom (อาจหลายหน้า), จำนวนแถวต่อหน้า, ทุก col, แถวรวม

### 3. ภส.๐๗-๐๒/๑(๒) — บัญชีสุราบรรจุขวด (portrait, 2 หน้า)
ข้อมูล: วันที่, ชนิด/ขนาดบรรจุ, จำนวนรับเข้า, จำนวนจ่ายออก, คงเหลือ, รวม
→ เก็บแบบเดียวกับใบ ๐๗-๐๑/๑

### 4. ภส.๐๗-๐๔/๑ — งบเดือน (landscape, 3 หน้า)
ข้อมูล: สรุปยอดรวมรายเดือน (ยกมา/ผลิต/จำหน่าย/คงเหลือ ของวัตถุดิบและสุรา)
→ ฟอร์มนี้ส่วนใหญ่เป็นช่องสรุป ไม่ใช่ตารางรายวัน: เก็บเป็น `point` รายช่องเป็นหลัก + บอกผมว่าช่องนั้นคือยอดอะไร

---

## รูปแบบส่งกลับ (ส่งแค่นี้พอ)

```
ฟอร์ม: ภส.๐๗-๐๒/๑(๑)
จำนวนแถวข้อมูล: 30 (ต่อหน้า)
หน้าที่มีตาราง: 1,2,3

[paste log จากปุ่มคัดลอกทั้งหมด]

การจับคู่คอลัมน์:
- col_ปริมาณที่ได้ = ปริมาณน้ำสุรา(ลิตร)
- col_ดีกรี = ดีกรี
- col_LPA = LPA
...
```

ผมรับแล้วเขียนฟังก์ชัน fill ให้เลย — เทสต์ฝั่งคุณ บอกผลเป็นคำพูด (เช่น "คอลัมน์ดีกรีเยื้องซ้าย 3 จุด") ผมขยับให้ ไม่ต้องส่งรูป
