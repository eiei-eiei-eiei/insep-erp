# Design system — "เหล็กกล้า" (Steel)

> ตัดสินใจ 2026-08-01 (D43) · ทิศทางเลือกจากตัวอย่าง 3 แบบ → "ห้องคุม" · ชุดสี → "เหล็กกล้า"
> **ไฟล์นี้คือกติกาฝั่ง UI เทียบเท่ากติกาเหล็กฝั่งสูตรใน CLAUDE.md — อ่านก่อนแตะหน้าตาแอปทุกครั้ง**

## หลักการ 3 ข้อ

1. **ห้ามเขียนสีตรง ๆ ใน component** — ไม่มี `bg-slate-800`, `text-red-500`, `#2563eb` ในไฟล์ `.tsx` อีก
   ใช้ token เท่านั้น (ดูตารางด้านล่าง) · ถ้าไม่มี token ที่ต้องการ = เพิ่ม token ไม่ใช่ hardcode
2. **สีแบรนด์เปลี่ยนตามลูกค้าได้ · สีสถานะล็อกตายทุกราย**
   เพราะ "เหลือง = มีของค้าง" ต้องแปลเหมือนกันทุกโรง เวลาสอนงาน/แก้ปัญหาทางโทรศัพท์
3. **โหมดมืดไม่ใช่การกลับสี** — เป็นค่าคนละชุดที่ปรับ contrast มาแล้ว
   (เช่น เขียว `#1a7f52` บนพื้นขาว ↔ `#4fb07c` บนพื้นดำ · ตัวหนังสือโหมดมืดไม่ใช่ขาวล้วน กันล้าตา)

## ทำไมเลือก "เหล็กกล้า"

โจทย์คือ **ขายให้โรงเหล้าหลายเจ้า** การไม่มีสีแบรนด์ตายตัวจึงเป็นข้อได้เปรียบ:
UI พื้นฐานเป็นเทาล้วน → สีแบรนด์แตะแค่ **4 จุด** (ปุ่มหลัก · แท็บที่เลือก · วงชื่อผู้ใช้ · แท่งกราฟชุดหลัก)
เปลี่ยนสีให้ลูกค้า = เปลี่ยนค่าเดียว ไม่ต้องไล่ปรับทั้งแอป และทำโหมดสว่างได้ง่ายที่สุด

## Token (นิยามจริงอยู่ใน `app/globals.css`)

### พื้นผิว
| token | ใช้กับ |
|---|---|
| `bg-page` | พื้นหลังหน้า (นอกการ์ด) |
| `bg-card` | การ์ด/กล่องเนื้อหา |
| `bg-nav` | แถบนำทาง · แถบสรุปยอดล่างจอ |
| `bg-input` | ช่องกรอก — **จมกว่าการ์ด** เพื่อให้รู้ว่าพิมพ์ได้ |
| `bg-raised` | หัวตาราง · hover · แถบที่ยกขึ้นเล็กน้อย |
| `bg-overlay/40` | ฉากหลัง modal — **ห้ามใช้ `bg-ink`** (โหมดมืด ink เป็นสีอ่อน ฉากจะสว่าง) |

### เส้น / ตัวอักษร
| token | ใช้กับ |
|---|---|
| `border-line` | เส้นขอบหลัก (การ์ด/ช่องกรอก/ปุ่ม) |
| `border-line-soft` | เส้นคั่นแถวในตาราง |
| `text-ink` | ข้อความหลัก · ตัวเลขเงิน |
| `text-muted` | ข้อความรอง · คำอธิบาย |
| `text-faint` | ป้ายกำกับ · หน่วย · ข้อความประกอบ |

### สถานะ — **ล็อกตาย ห้ามให้ลูกค้าเปลี่ยน**
| ความหมาย | token | ใช้เมื่อ |
|---|---|---|
| ปกติ/สำเร็จ | `text-ok` `bg-ok-bg` `border-ok-line` | ปิด batch แล้ว · บันทึกสำเร็จ · ชำระครบ |
| ค้าง/รอดำเนินการ | `text-warn` `bg-warn-bg` `border-warn-line` | หม้อยังไม่จบ · รอคลังแพ็ค · ยังไม่ได้สร้างรายงาน |
| ผิดพลาด/เกินกำหนด | `text-crit` `bg-crit-bg` `border-crit-line` | error · เกินกำหนดชำระ · ปุ่มยกเลิก/ลบ |

### แบรนด์ — เปลี่ยนตามลูกค้าได้
| token | ใช้กับ |
|---|---|
| `bg-brand` + `text-on-brand` | ปุ่มหลัก (สิ่งที่ผู้ใช้ควรทำต่อ) — **คู่กันเสมอ** |
| `text-brand` | ลิงก์ · แท็บที่เลือกอยู่ · ตัวเลขที่ต้องเน้น |
| `bg-brand-soft` | พื้นแท็บที่เลือก · วงชื่อผู้ใช้ (คำนวณจาก `color-mix` 12%) |
| `border-brand-line` | เส้นขอบของสิ่งที่ผูกกับแบรนด์ (32%) |

### กราฟ
`chartColor(i)` จาก `lib/shared/chart.ts` (8 สีวนซ้ำ) · `CHART_GRID` `CHART_LABEL` `CHART_AXIS_LABEL`
**กติกา**: กราฟชุดหลักใช้สีแบรนด์ · ชุดรองใช้ `--color-series` (เทา) · **ห้ามใช้เขียว/แดง** ในกราฟ
เพราะสองสีนั้นสงวนให้สถานะ — ไม่งั้นแท่ง "รายจ่าย" สีแดงจะอ่านเหมือน "มีข้อผิดพลาด"

## ระดับของปุ่ม (3 ระดับ ไม่ใช่ 7 สี)

| ระดับ | หน้าตา | ใช้เมื่อ |
|---|---|---|
| primary | `bg-brand text-on-brand` | สิ่งที่ควรทำต่อในหน้านั้น — **มีได้ 1 อันต่อกลุ่ม** |
| secondary | `border-line bg-card text-muted` | ทำได้ ไม่เร่ง (พิมพ์ · แก้ไข · ดูรายละเอียด) |
| danger | `border-crit-line text-crit` | ทำลาย/ย้อนกลับไม่ได้ (ยกเลิก · ลบ) — **แยกระยะจากปุ่มอื่น** |

component พร้อมใช้: `SaveButton` `RowBtn` `IconBtn` `Badge` ใน `lib/shared/ui.tsx`

## ไอคอน

ใช้ `lib/shared/icons.tsx` (SVG เส้น สืบสีจาก `currentColor`) — **ห้ามใช้อิโมจิเป็นปุ่ม/ไอคอน**
เหตุผล: อิโมจิเปลี่ยนหน้าตาตาม OS, ปรับสี/ขนาดไม่ได้, และตอนเดโมขายจะดู "ทำเล่น"
*(อิโมจิในข้อความอธิบาย เช่น "⚠️ กิจการนี้ยังไม่มีเลขสรรพสามิต" ยังใช้ได้ — อ่านเป็นเครื่องหมายวรรคตอน)*

## ตาราง

ทุกตารางใช้ `<table className="tbl">` — สไตล์อยู่ใน `globals.css` **layer `components`**
จึงเป็นแค่ "ค่าเริ่มต้น" · utility class ที่ใส่ราย `th`/`td` ยังทับได้เสมอ

```tsx
<TableWrap minWidth={620}>
  <table className="tbl">
    <thead><tr><th>วันที่</th><th className="num">ยอด</th></tr></thead>
    <tbody>
      <tr><td>01/08/69</td><td className="num">1,240.00</td></tr>
      <tr className="editing">…</tr>   {/* แถวที่กำลังแก้ inline */}
    </tbody>
  </table>
</TableWrap>
```

| คลาส | ผล |
|---|---|
| `.tbl` | หัวตารางตัวพิมพ์ใหญ่/เล็ก/muted · เส้นคั่นแถว · padding · hover |
| `td.num` / `th.num` | ชิดขวา + `tabular-nums` + ไม่ตัดบรรทัด |
| `td.act` | ช่องปุ่มท้ายแถว (ชิดขวา ไม่ตัดบรรทัด) |
| `tr.editing` | แถวที่กำลังแก้ inline (พื้นสีเตือน) |

**ห้ามใส่ `p-1` / `px-2 py-1` / `text-left` ราย cell อีก** — `.tbl` คุมให้แล้ว
ใส่ได้เฉพาะที่เป็นข้อยกเว้นจริง: ความกว้าง (`w-32`), สี (`text-crit`), `whitespace-nowrap`

## ตัวเลข

ยอดเงิน/ดีกรี/ปริมาณ ใส่คลาส `tnum` (tabular-nums) และชิดขวา → **หลักหน่วยตรงกันทุกแถว** กวาดตาเทียบได้เร็ว
`NumInput` / `NumBox` ทำให้แล้วอัตโนมัติ

## Touch target

ปุ่มในลิสต์/ตาราง: `min-h-[44px]` บนจอเล็ก แล้วยุบเป็นขนาดปกติที่ `sm:` ขึ้นไป
หน้าที่ใช้นอกสถานที่ (จัดการออเดอร์ · คลัง) ห้ามต่ำกว่านี้

## แบรนด์ต่อลูกค้า (white-label)

ค่าอยู่ใน `app_settings` ของแต่ละ tenant (migration 0022) — **deploy โค้ดใหม่ไม่กระทบ**
เพราะโค้ดอยู่ที่ Vercel ส่วนค่าอยู่ที่ Supabase ของลูกค้า คนละที่กัน

| kind | ค่า |
|---|---|
| `brand_name` | ชื่อที่แสดงบนแถบเมนู |
| `brand_color` | ชื่อชุดสี (`steel`/`copper`/`green`/`indigo`/`wine`/`teal`/`rust`) — **ไม่ใช่รหัสสี** |
| `logo_url` | ลิงก์โลโก้ (ว่าง = ใช้ตัวอักษรแรกของชื่อ) |
| `default_mode` | `light` / `dark` (โหมดตอนเปิดครั้งแรก) |

แก้ได้จากแอป: **บัญชี → แท็บตั้งค่า → การ์ด "แบรนด์ของกิจการ"**

**ทำไมเก็บชื่อชุดสีไม่ใช่รหัสสี**: แต่ละชุดมีค่าคู่ สว่าง/มืด ที่ตรวจ contrast แล้ว
ถ้าให้กรอก hex เอง ลูกค้าเลือกเหลืองมะนาว → ตัวหนังสือบนปุ่มอ่านไม่ออก → กลายเป็นงานซัพพอร์ต

**เพิ่มสีใหม่**: เพิ่ม 2 บล็อกใน `globals.css` (สว่าง/มืด) + 1 แถวใน `BRAND_COLORS` (`lib/shared/branding.ts`)
+ แก้ CHECK constraint ใน migration ใหม่ · เฉดอ่อน/เส้นขอบคำนวณเองด้วย `color-mix`

⚠️ **กับดักที่เคยเจอ**: `data-mode` อยู่บน `<html>` (อ่านจาก cookie ฝั่ง server) แต่ `data-brand`
อยู่บน div ใน `(app)/layout.tsx` (กว่าจะรู้แบรนด์ต้อง login ก่อน) → selector ต้องเขียน
ทั้ง `[data-mode="dark"] [data-brand="x"]` (ลูกหลาน) และ `[data-mode="dark"][data-brand="x"]` (ธาตุเดียวกัน)

## สิ่งที่ **ไม่** ผูกกับธีม (ห้ามแตะ)

- `app/(app)/sales/_components/print.ts` — เอกสารการค้าสำหรับพิมพ์
- `lib/accounting/reportHtml.ts` — ภพ.30 / ภงด. สำหรับพิมพ์
- `lib/pdf/*` — ฟอร์มราชการ ภส./50ทวิ (กติกาเหล็ก #3: ห้ามเพี้ยนแม้ 1 mm)

เอกสารพิมพ์ต้อง **ดำบนขาวเสมอ** ไม่ว่าผู้ใช้เปิดโหมดไหน — ถ้าเผลอทำให้ตามธีม กระดาษที่พิมพ์จะเป็นพื้นดำ

## รัศมีมุม (radius)

ใช้ 3 ค่าเท่านั้น — ห้ามเพิ่มค่าอื่น:

| คลาส | ใช้กับ |
|---|---|
| `rounded` (4px) | ป้ายสถานะ · ปุ่มในตาราง · ช่องกรอก · แท็บ |
| `rounded-lg` (8px) | การ์ด · กล่อง · modal · ปุ่มหลัก |
| `rounded-full` | avatar · chip · pill ที่เป็นวงกลมจริง |

*(เดิมมี `rounded-2xl`/`rounded-xl` ปนอยู่ 23 จุด — ยุบเป็น `rounded-lg` แล้วใน D43 polish)*

## สถานะความสะอาดของโค้ด (ตรวจได้ด้วยคำสั่ง)

```bash
grep -rn "\(bg\|text\|border\)-\(slate\|amber\|green\|red\|blue\)-[0-9]" app --include=*.tsx | grep -v print.ts
```
**ต้องได้ 0 บรรทัด** — ถ้ามีขึ้นมาแปลว่ามีคนเขียนสีดิบเข้ามาใหม่

## ที่ยังเหลือ (polish รอบถัดไป)

- **อัปโหลดโลโก้เข้า Supabase Storage** — ตอนนี้วาง URL เอง (ยังไม่มีโลโก้จริงจึงยังไม่ทำ)
  เมื่อมีโลโก้แล้วต้องเพิ่ม: bucket `branding` + ปุ่มอัปโหลดในการ์ดแบรนด์

  — หน้าหลังนี้ใช้ inline style เพราะ CSS อาจโหลดไม่สำเร็จ จึงใช้ไอคอน SVG ไม่ได้
